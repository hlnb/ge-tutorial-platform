# Black Swan Bistro - Completed Reference Site

This is the canonical completed plain HTML and CSS version of the Black Swan Bistro guided project.

It represents the site learners should have after the multi-page, polish, production-readiness, and deployment stages. The earlier reference versions remain available under:

- `public/projects/html-basics/black-swan-bistro/`
- `public/projects/css-basics/black-swan-bistro/`

## Pages

- `index.html` - homepage
- `menu.html` - complete menu
- `about.html` - restaurant story, values, and team
- `contact.html` - practical details, hours, location, and demonstration forms

## Shared assets

- `assets/css/style.css`
- `assets/js/site.js`
- `assets/images/`

The forms are intentionally demonstrations. They do not send or store visitor information.
